# Правила калькуляции FIN

- Работы: часы по ролям × ставка из утверждённого rate card; диапазон min–max.
- Лицензии и оборудование: только по коммерческому предложению поставщика; без него — NEEDS_VENDOR_QUOTE.
- Поддержка: отдельной строкой, помесячно.
- НДС (TVA): ставка и основание — только из загруженной актуальной редакции Налогового кодекса РМ
  с датой проверки; иначе NEEDS_VERIFICATION и сумма с НДС не выводится.
- Счета: только черновики; выпуск factura fiscală — после одобрения FIN-HUMAN.
