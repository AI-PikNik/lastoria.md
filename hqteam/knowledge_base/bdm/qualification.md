# Квалификация лидов HQTeam (BANT + элементы MEDDICC)

- Budget: есть ли сигнал бюджета / бюджетного цикла.
- Authority: известна ли роль контакта (ЛПР / влияющий).
- Need: совпадают ли боли с услугами HQTeam (каталог услуг).
- Timeline: есть ли срок/триггер (аудит, инцидент, открытие филиала).
- Metrics / Pain (MEDDICC): измеримый эффект для бизнеса.

## Правила работы с контактами и согласиями
- У каждого лида обязателен источник (откуда получен контакт).
- Контакт без подтверждённого согласия/законного основания не используется для рассылки.
- Массовые рассылки запрещены; любое письмо клиенту — только после одобрения человеком.
- Контакты не выдумываются; при отсутствии — вопрос в open questions.
